# Задание №2

Необходимо реализовать систему уведомлений.
Система должна уметь:
1. Отправлять по email
2. Отправлять по SMS
3. Отправлять по Телеграм
4. Отправлять данные в кодированном виде
5. Отправлять данные в сжатом виде
6. Отправлять данные только в хэшированном виде

Используйте паттерн Декоратор для реализации объектов уведомлений.
1. Реализуйте интерфейс уведомлений
2. Реализуйте объекты уведомлений
3. Реализуйте объект декоратор
4. Реализуйте объекты позволяющие декорировать
5. Реализуйте объект Example, который получает при своей инициализации данные в виде строки, 
отправляет их в Телеграм в кодированном и сжатом виде. А затем отправляет хэш данных на почту.
