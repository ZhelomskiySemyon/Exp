# Задание №2

1. Есть компьютерная игра - симулятор охотника. 
В игре есть пруд с утками и селезнями, утки и селезни как все семейство уток умеют ходить, есть и летать. 
Заказчик расширяя функционал добавляет уткам новую функцию - летать. 
Используя паттерн Стратегия реализуйте этот этап игры. 
Заложите разное поведение полета для утки и селезня, утки летают просто, 
а селезни летают с планированием в воздухе, чтобы охотник(игрок) распознал в воздухе их отличие.
2. Заказчик расширяет функционал, чтобы игра приобрела новые краски добавляет 
новый вид уток - резиновые утки. 
Реализуйте класс резиновой утки со всем присущим поведением семейства, но нужно помнить, 
что эти утки не могут ходить, есть и летать.
3. Заказчик расширяет функционал, 
звукозапись готова и нужно добавить всем видам уток способность крякать, 
утки и селезни издают один звук, а вот резиновые утки могут только пищать.
4. Заказчик расширяет функционал, 
подъехала новая запись звука, после выстрела в резиновую утку при взаимодействии с ней 
она больше не издает звуков, и плавать больше не умеет, 
это из имеющихся единственная утка, которая не удаляет свой объект заменяя ее на добычу, 
а остается собой изменяя одно или несколько из своих поведений
