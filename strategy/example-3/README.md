# Задание №3

Вводные:
Программируем на объектах реального мира.
Школа, урок математики, классная руководительница Мария Ивановна, ученики Вова и Маша.

Выполняем:
1. Реализуем объект "Мария Ивановна", она может преподавать, отвечать на вопрос ученика.
2. Реализуем объект Вова и объект Маша, это ученики, у каждого из них есть хорошее поведение и плохое, ученики могут демонстрировать свое поведение, задавать вопросы, учиться
3. Реализуем объект Урок и метод математика.
4. В методе математика реализуем такую последовательность
    1. Объявляем на уроке учителя
    2. Объявляем на уроке Машу и Вову
    3. Вова в плохом настроении и его поведение "плохое", а маша в хорошем и ее поведение "хорошее"
